**Worship Presenter** adalah aplikasi inovatif yang dirancang khusus untuk mempermudah operator multimedia dalam ibadah gereja atau acara kerohanian. Aplikasi ini menyajikan lirik lagu (Buku Ende / Lagu Sion), ayat Alkitab, dan media dengan antarmuka yang sangat elegan, responsif, dan mudah digunakan (User-Friendly).

Diciptakan dengan visi "Membawa Presentasi Ibadah ke Tingkat Selanjutnya", aplikasi ini menonjolkan estetika *glassmorphism*, kontrol yang sangat intuitif, serta database ultra-cepat dan bisa digunakan secara **Offline**.

---

## ✨ Fitur Unggulan

### 1. Dual-Screen Cerdas (Layar Operator & Jemaat)
- **Control Panel**: Layar untuk operator dengan kontrol lirik secara langsung, *preview* langsung yang tidak bocor ke layar utama.
- **Display Window**: Jendela terpisah untuk dilempar ke Proyektor / Layar Utama. Resolusi fleksibel dan menyesuaikan.

### 2. Database Super Cepat & Offline (TSV / IndexedDB)
- Memuat ribuan lagu dan puluhan ribu ayat Alkitab **tanpa loading**.
- Tidak memerlukan koneksi internet untuk beroperasi jika menggunakan versi Desktop (`.exe`).

### 3. Database Manager & Kustomisasi
- Tambahkan lagu kustom Anda sendiri atau modifikasi lagu yang ada.
- **Backup & Restore**: Ekspor (*download*) karya lagu kustom dan Playlist Anda ke dalam format standar `.tsv`, dan impor (*upload*) kembali di komputer mana saja!
- Ubah versi Alkitab sesuka Anda.

### 4. Playlist & Ibadah Terjadwal
- Susun *rundown* / *playlist* ibadah dari rumah.
- Seret dan lepas (Drag & Drop) untuk menyusun urutan acara.

### 5. Estetika "WOW" & Background Dinamis
- UI dirancang menggunakan prinsip modern. Transisi mulus, tombol bercahaya, dan tata letak minimalis.
- Ganti latar belakang presentasi Anda secara instan menggunakan gambar apa pun, disesuaikan langsung dari Control Panel.

## 🚀 Mengunduh & Menggunakan Aplikasi (Offline)

Tidak perlu repot menginstal atau menyambungkan internet saat sedang bertugas!

1. Buka folder `frontend/release/` di dalam repositori ini.
2. Anda akan menemukan folder bernama `WorshipPresenter-win32-x64`.
3. **Copy seluruh folder tersebut ke dalam Flashdisk atau Laptop mana saja (Windows).**
4. Buka folder tersebut dan klik dua kali pada file bernama **`WorshipPresenter.exe`**.
5. Aplikasi akan langsung menyala, tanpa layar Login (Anda langsung memiliki hak akses Admin) dan data akan tersimpan aman di file lokal `database.json`.

---

## 🛠️ Dibangun Dengan Teknologi Modern

- **Frontend**: React + TypeScript + Vite + TailwindCSS
- **Desktop Wrapper**: Electron
- **Database Lokal**: Format standar .TSV + IndexedDB
