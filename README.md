**Worship Presenter** adalah aplikasi inovatif yang dirancang khusus untuk mempermudah operator multimedia dalam ibadah gereja atau acara kerohanian. Aplikasi ini menyajikan lirik lagu (Buku Ende / Lagu Sion), ayat Alkitab, dan media dengan antarmuka yang sangat elegan, responsif, dan mudah digunakan (User-Friendly).

Diciptakan dengan visi *"Membawa Presentasi Ibadah ke Tingkat Selanjutnya"*, aplikasi ini menonjolkan estetika *glassmorphism*, kontrol yang sangat intuitif, serta database ultra-cepat yang bisa digunakan secara **100% Offline** — tanpa internet, tanpa akun, tanpa berlangganan.

---

## ✨ Fitur Unggulan

### 1. Dual-Screen Cerdas (Layar Operator & Jemaat)
- **Control Panel**: Layar untuk operator dengan kontrol lirik secara langsung, *preview* langsung.
- **Display Window**: Jendela terpisah untuk dilempar ke Proyektor / Layar Utama. Resolusi fleksibel dan menyesuaikan.

### 2. Database Super Cepat & Offline (TSV / IndexedDB)
- Memuat ribuan lagu dan puluhan ribu ayat Alkitab **tanpa loading**.
- Tidak memerlukan koneksi internet untuk beroperasi.

### 3. Rich Text Editor & Pewarnaan Lirik
- Warnai lirik langsung di layar editor (Merah, Kuning, Hijau, Biru, Ungu, Oranye).
- Warna terlihat langsung tanpa kode tag — seperti Microsoft Word.

### 4. Database Manager & Kustomisasi
- Tambahkan lagu kustom Anda sendiri atau modifikasi lagu yang ada.
- **Backup & Restore**: Ekspor karya lagu kustom dan Playlist Anda ke format `.tsv`, dan impor kembali di komputer mana saja!
- Ubah versi Alkitab sesuka Anda.

### 5. Playlist & Ibadah Terjadwal
- Susun *rundown* / *playlist* ibadah dari rumah.
- Seret dan lepas (Drag & Drop) untuk menyusun urutan acara.
- Dukungan Video (File Lokal & YouTube Link).
- Countdown Timer, Pengumuman, dan Slideshow.

### 6. Estetika "WOW" & Background Dinamis
- UI dirancang menggunakan prinsip modern. Transisi mulus, tombol bercahaya, tata letak minimalis.
- Ganti latar belakang presentasi secara instan menggunakan gambar apa pun, langsung dari Control Panel.

## 🚀 Mengunduh & Menggunakan Aplikasi

> **Tidak perlu install atau koneksi internet!**

1. Buka halaman **[Releases](https://github.com/pisgahbisdac/PB/releases)** dan unduh versi terbaru.
2. Extract file zip yang diunduh.
3. Buka folder hasil extract dan klik dua kali **`WorshipPresenter.exe`**.
4. Aplikasi langsung menyala. Data tersimpan aman di file lokal `database.json` di folder yang sama.
