Panduan Update Worship Presenter

Ikuti salah satu cara di bawah agar data lama Anda tidak hilang saat berganti ke versi baru!

PALING CEPAT

Cara 1: Copy File

  • 1

    Buka folder aplikasi VERSI LAMA.

  • 2

    Cari file bernama database.json (sebelah file .exe).

  • 3

    Copy (Salin) file tersebut.

  • 4

    Buka folder aplikasi VERSI BARU, lalu Paste file tersebut ke dalamnya.

LEBIH AMAN

Cara 2: Backup Menu

  • 1

    Buka aplikasi VERSI LAMA milik Anda.

  • 2

    Masuk ke menu Pengaturan ⚙️ → tab Backup.

  • 3

    Klik tombol Backup Keseluruhan untuk men-download data.

  • 4

    Tutup versi lama, buka aplikasi VERSI BARU, masuk ke menu yang sama lalu Upload file backup tadi.

💡 Tips: Dengan melakukan cara di atas, semua daftar Rundown, Custom Song, dan Pengaturan Anda akan tetap aman dan bisa langsung digunakan!
