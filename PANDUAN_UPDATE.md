# Panduan Update Aplikasi Worship Presenter 🔄

Ikuti salah satu cara di bawah ini agar **semua data lama Anda (Daftar Rundown, Lagu Custom, dan Pengaturan)** tetap aman dan tidak hilang saat beralih ke versi baru!

---

## ⚡ CARA 1: Paling Cepat (Copy File)

Gunakan cara ini jika Anda merasa nyaman mengatur file di komputer Anda.

> [!TIP]
> **Inti dari cara ini:** Kita hanya perlu memindahkan otak datanya (`database.json`) dari aplikasi lama ke aplikasi baru.

1. Buka folder **Aplikasi VERSI LAMA**.
2. Cari file bernama `database.json`. *(File ini berada persis di sebelah file `WorshipPresenter.exe`)*
3. **Copy** (Salin) file `database.json` tersebut.
4. Buka folder **Aplikasi VERSI BARU** yang sudah Anda download/ekstrak.
5. **Paste** (Tempel) file `database.json` tersebut ke dalamnya (Timpa/Replace jika sudah ada).

✅ **Selesai!** Saat Anda membuka versi baru, semua data lama otomatis akan langsung muncul.

---

## 🛡️ CARA 2: Paling Aman (Lewat Menu Backup)

Gunakan cara ini jika Anda ingin mencadangkan (backup) data Anda dengan lebih rapi langsung dari aplikasinya.

> [!NOTE]
> **Inti dari cara ini:** Kita men-download file backup dari versi lama, lalu meng-upload-nya di versi baru.

1. Buka **Aplikasi VERSI LAMA** milik Anda.
2. Masuk ke menu **Pengaturan** (ikon roda gigi ⚙️) &rarr; lalu klik tab **Backup**.
3. Klik tombol **"Backup Keseluruhan"** untuk men-download data Anda. Simpan file `.json` yang terunduh di tempat yang mudah ditemukan.
4. Tutup aplikasi versi lama.
5. Buka **Aplikasi VERSI BARU**.
6. Masuk kembali ke menu **Pengaturan** &rarr; tab **Backup**.
7. Di bagian Impor, pilih file backup yang baru saja Anda download pada Langkah 3.

✅ **Selesai!** Aplikasi baru sudah memuat semua lagu Custom dan Playlist dari komputer Anda.

---
**💡 Tips Tambahan:**
Simpan baik-baik panduan ini agar anggota tim Anda bisa langsung paham saat harus memperbarui aplikasi di laptop operasional!
